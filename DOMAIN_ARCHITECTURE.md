# Zuelen domain architecture

Canonical public website: https://zuelen.lu

Application: https://app.zuelen.lu

Redirects:
- https://www.zuelen.lu -> https://zuelen.lu
- https://zuelen.com -> https://zuelen.lu
- https://www.zuelen.com -> https://zuelen.lu

The application host is intentionally separate from the marketing website so authentication, product routes and future public-site changes can evolve independently.
